# Wireshark – Network Traffic Analysis

## Overview

This repository documents my hands-on learning experience with Wireshark through six practical labs completed as part of my cybersecurity internship at NetworkWalks.

The exercises focused on network traffic analysis, protocol investigation, identification of suspicious activities, and understanding security weaknesses in unencrypted communications.

## Labs Covered

| Lab | Topic | Key Concepts |
|---|---|---|
| 01 | Identify the Attacker | TCP SYN scan, IP analysis, port scanning |
| 02 | Follow TCP Stream – Part 1 | TCP stream reconstruction, traffic inspection |
| 03 | Follow TCP Stream – Part 2 | HTTP requests, hidden information, HTML comments |
| 04 | HTTP Plain Text Credentials | HTTP POST, credential exposure, TLS |
| 05 | Catch the Brute Force Attacker | FTP, authentication failures, response codes |
| 06 | Catch the Call Scammer | SIP, RTP, audio analysis, PCMU codec |

## Skills & Concepts Explored

- Wireshark packet capture and analysis
- Display filters and traffic isolation
- TCP flags and three-way handshake
- IP address and port analysis
- TCP stream reconstruction
- HTTP request and response inspection
- FTP authentication analysis
- VoIP traffic analysis (SIP/RTP)
- Identification of security weaknesses in unencrypted communications

## Tools

- Wireshark
- TShark (command-line concepts)

## Repository Structure

Each lab contains its objectives, investigation methodology, relevant display filters, observations, and key takeaways.

## Learning Outcomes

These practical exercises helped me develop a better understanding of network communication, identify suspicious activities, inspect application-layer protocols, and recognize the security implications of transmitting sensitive information without encryption.
